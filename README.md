# Abhay Tripathi Portfolio

A responsive single-page portfolio built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html` to the repository root.
3. Commit the file.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace the email link with your complete email address.
- Check skill tags and remove anything you haven't learned yet.
- Replace GitHub profile links in project cards with each project's actual repository or live website.
- Add a resume PDF link if you want a Resume button.
